# Compilers Question Bank (CS445)

Past exam, midterm and quiz questions, solved from the slides and sorted by slide deck.

Open `index.html` in any browser. No installation or server is needed.

- Pick a chapter, or "All chapters mixed" for a mock exam.
- Each page has one question, with Show solution, Previous, Shuffle and Next.
- Each solution shows the deck and slide the answer comes from, plus the exam it came from.
- When you finish a set, use "Review my mistakes". The home page keeps a list of all your mistakes.

Keys: `←` `→` move, `1`–`6` pick an option, `Enter` shows the solution, `S` shuffles.

Your answers are saved in this browser only.

| File | Purpose |
|---|---|
| `index.html` | The website |
| `questions.js` | All questions, answers, explanations and sources |
| `img/` | Figures cropped from the exam papers |

Keep this folder next to `slides/`. The "Open slide" links use that relative path.
